The nine differences

Pick one to jump to that part of the video.

  1. 1

    Zero pipeline

    Upload files and search them. No re-ranker, no chunker, no embedder. You don't build it and you don't babysit it.

  2. 2

    Files stay files

    A piece of a file is an atom. Every atom stays connected to its source file, path and version.

  3. 3

    Flat context cost

    A search hands back a ranked window you can page through. The files and bytes stay outside the context window.

  4. 4

    Multimodal, one store

    Text, image, video and audio on the same atoms search layer. No pipeline for each modality.

  5. 5

    Governance built in

    Tags, access control for each store, and scoped tokens you mint yourself.

  6. 6

    Made for agents

    MCP first, REST for large files. It describes its own capabilities and skills, so there is no custom retrieval code.

  7. 7

    Change your mind

    Update a file, re-tag it, delete it or revert it, in place, without a whole new build.

  8. 8

    Corpus-wide queries

    One question can span the whole corpus and still fit into a tiny context window, on any model.

  9. 9

    Multiplayer

    One shared store for every agent and every team: Codex, Claude Code, Cursor or your own IDE.

In the jurisdiction you choose, including on your own hardware. Each store is isolated, encrypted at rest and never used to train models.
